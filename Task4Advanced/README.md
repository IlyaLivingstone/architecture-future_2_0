## Файлы

- [bounded-contexts.puml](bounded-contexts.puml) — карта ограниченных контекстов ([png](bounded-contexts.png));
- [event-storming.puml](event-storming.puml) — Event Storming ([png](event-storming.png));
- [aggregates.md](aggregates.md) — агрегаты: границы, инварианты, ключи;
- [events.md](events.md) — каталог доменных событий и подписчиков;
- [justification.md](justification.md) — почему события, а не шина Camel и общий DWH.

Рендер: `plantuml -charset UTF-8 -tpng *.puml` из этого каталога или предпросмотр
PlantUML в IDE.
